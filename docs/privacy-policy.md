# ChatGPT 对话保存助手隐私说明

## 我们收集什么

插件核心功能默认在本地运行。只有当你主动使用卡密功能或插件拉取公告配置时，才会访问第三方服务 `seat.20050225.xyz`。

在这些场景中，可能会处理以下数据：

- 卡密
- 绑定邮箱
- 插件生成的客户端标识 `client_id`

## 我们不会收集什么

以下内容不会发送到第三方卡密服务：

- ChatGPT 对话正文
- 导出的 HTML、Markdown、PDF、JSON 内容
- 用户上传文件和 ChatGPT 生成文件的文件内容
- 用户选择的本地保存目录路径

## 数据保存位置

插件会在浏览器本地存储中保存以下信息：

- 保存目录授权状态
- 导出格式设置
- 自动保存开关
- 卡密状态缓存
- 使用统计与少量 UI 状态

用户导出的对话、附件、生成文件和上下文 JSON 会保存到你自己选择的本地文件夹。

## 联网说明

插件会访问以下域名：

- `chatgpt.com`
- `chat.openai.com`
- `seat.20050225.xyz`

其中：

- `chatgpt.com` / `chat.openai.com` 用于读取当前对话页面和下载当前会话中的文件。
- `seat.20050225.xyz` 仅用于卡密激活、卡密状态校验、换绑设备和获取插件公告配置。

## 联系方式

如果你需要把这份隐私说明放到 Chrome Web Store，请将本文件发布到一个可公开访问的 HTTPS 地址，并把该地址填写到商店后台的 Privacy Policy 字段。
