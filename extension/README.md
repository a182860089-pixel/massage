# ChatGPT Saver Extension

## Installation Instructions

1. **Open Extensions Page**:
   - Chrome: Go to `chrome://extensions`
   - Edge: Go to `edge://extensions`

2. **Enable Developer Mode**:
   - Toggle the "Developer mode" switch in the top right corner.

3. **Load Extension**:
   - Click the "Load unpacked" button.
   - Select this folder (`F:\chat-massage\extension`).

## Features
- **Auto Save**: Save conversations as HTML, Markdown, or PDF.
- **Usage Monitor**: Track usage for GPT-5.2 models.
- **Context Import/Export**: Transfer conversation context between chat sessions.
